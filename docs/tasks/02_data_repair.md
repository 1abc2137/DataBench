# 第 2 组表格数据修复任务书

## 目标和边界

模块 ID 为 `data_repair`，代码目录为 `modules/data_repair/`。系统接收已经给出的错误位置并生成候选修复值，不负责发现函数依赖，也不依赖第 4 组。

## 输入和输出

- 输入：脏 CSV、错误位置 `[{row_id,column}]`，以及可选的干净真值表。
- 输出：`[{row_id,column,old_value,new_value,confidence,evidence}]`。
- 不修改原始文件；页面展示修复预览并允许导出副本。
- `task_type` 固定为 `data_repair`。

## 两种基础方法

1. 频率修复：使用列众数、分组众数或候选值频率，对每个修改保留规则说明。
2. 相似记录修复：按其他字段计算简单相似度或 kNN，从邻近记录聚合候选值。

Baran 和 HoloClean 可用于方法讨论，但第一阶段不要求复现完整概率系统。

## 第一阶段数据集

- 从一个不超过 100 行的干净人工表生成 `clean.csv`。
- 复制并注入至少 10 个已知错误，生成 `dirty.csv` 和 `error_cells.csv`。
- `clean.csv` 作为修复值真值；数据卡记录注入方式和随机种子。

## 评价

- 指定错误位置上的修复值准确率。
- 当系统允许“不修改”或产生额外修改时，报告 repair precision、recall 和 F1。
- 展示修改前后值、置信度、失败案例和运行时间。

## 最小交付

- 两种方法在同一 dirty-clean 数据对上运行和对比。
- 页面加载脏表与错误位置，展示候选修复和评测。
- 测试非法行号、未知列、空错误列表和无法生成候选值的情况。

## 不做事项

- 不执行函数依赖发现。
- 不直接覆盖用户原始 CSV。
- 没有干净真值时不报告修复准确率。
