# 第 5 组多源真值发现任务书

## 目标和边界

模块 ID 为 `truth_discovery`，代码目录为 `modules/truth_discovery/`。系统从多个来源对同一对象属性的冲突声明中估计真值和来源可靠性，不做实体匹配。

## 输入和输出

- 输入：长表，至少包含 `source_id`、`object_id`、`attribute` 和 `value`，以及可选真值表。
- 输出：`[{object_id,attribute,truth_value,confidence,evidence}]`。
- `metadata` 可记录来源可靠性估计和收敛次数。
- `task_type` 固定为 `truth_discovery`。

## 两种基础方法

1. 多数投票：按对象和属性统计声明频率，明确平票规则。
2. 迭代加权投票：根据当前真值估计更新来源可靠性，再重新计算值置信度，设置收敛阈值和最大迭代数。

第二种方法可以参考 TruthFinder 思想或公开比较框架，但必须清楚标注是简化实现还是论文复现。

## 第一阶段数据集

- 构造至少 5 个来源、30 个对象属性对的冲突声明。
- 设定来源可靠性差异、平票、缺失覆盖和少量恶意来源。
- 保存对象属性真值表；数据卡记录生成规则和随机种子。

## 评价

- 有真值时报告 truth accuracy，并分场景比较覆盖率和冲突程度。
- 来源可靠性有生成真值时，报告排序相关或绝对误差。
- 展示每个真值的支持来源和置信度，不只给最终标签。

## 最小交付

- 两种方法在同一人工数据上运行并产生差异分析。
- 页面展示真值、置信度、支持来源和来源可靠性。
- 测试单一来源、无冲突、全部冲突、平票和不收敛保护。

## 不做事项

- 不把来源可靠性直接解释为现实世界的可信度结论。
- 不混入实体消歧或记录匹配任务。
- 无真值时不报告 truth accuracy。
