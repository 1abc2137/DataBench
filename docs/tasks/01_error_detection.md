# 第 1 组表格错误检测任务书

## 目标和边界

模块 ID 为 `error_detection`，代码目录为 `modules/error_detection/`。系统定位疑似错误单元格并给出错误类型、分数和证据，不自动修改数据。

## 输入和输出

- 输入：单个 CSV，以及可选的单元格级真值文件。
- 主表必须通过 `load_csv` 获得稳定 `__row_id`。
- 输出：`[{row_id,column,error_type,score,evidence}]`。
- `task_type` 固定为 `error_detection`。

## 两种基础方法

1. 规则检测：缺失值、类型异常、取值范围或枚举领域违反。规则由页面参数或配置文件明确给出。
2. 统计检测：对数值列使用 IQR 或稳健 Z 分数，对低频类别提供可解释的异常分数。

Raha 或 REIN 可用于理解研究方向，但第一阶段不要求完整复现论文系统。

## 第一阶段数据集

- 继续使用 `datasets/samples/errors_demo.csv` 验证现有缺失值基线。
- 另建一份不超过 100 行的人工样例，包含缺失、类型、范围和类别错误。
- 建立单元格真值文件，至少包含 `row_id`、`column` 和 `error_type`。
- 数据卡注明人工注入规则和随机种子。

## 评价

- 有真值时报告 cell precision、recall 和 F1，并区分错误类型。
- 无真值时只展示疑似单元格数量、分数和证据。
- 记录每种方法的运行时间和参数。

## 最小交付

- 两种方法均能在人工样例运行。
- 页面可以上传 CSV、选择方法、设置参数、查看结果并保存实验。
- 至少测试空表、保留列冲突、无错误数据和已知错误数据。

## 不做事项

- 不自动替换单元格。
- 不依赖第 2 组修复模块。
- 不把无监督异常分数解释为已经确认的错误标签。
